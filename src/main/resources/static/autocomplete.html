Online Booking Instructions
線上訂票須知

線上訂票規則說明

  1. 未滿 2 歲且不佔位之兒童無需購票，可免費入場觀賞。
  2. 若交易內含餐飲品項，須至購票影城櫃檯領取電影票與餐點。
  3. 網路訂票每張票需加收 NT$20 手續費。
  4. 片長 150 分鐘以上之電影需加價。
  5. 為維護顧客權益，惡意佔位或影響他人正常訂位使用者，影城保有取消訂位之權利。

退換票規定

  1. 完成線上付款並取票者，若需退票請依影城規定於指定時間內辦理。
  2. 尚未取票者，可於電影開演前依規定辦理退款。
  3. 電影票遺失恕不補發。
  4. 如遇特殊事故取消電影放映，將依影城公告辦理退換票。

訂票取票注意事項

  1. 完成線上訂票後，請依訂單資訊至影城取票。
  2. 請確認場次、日期、座位與票種資訊是否正確。
  3. 取票時請備妥訂單編號或相關證明。
  4. 開演後是否可入場，依影城現場規定辦理。
Movie Rating System
電影分級制度說明

依照相關規定，電影分級制度如下：

  1. 普遍級 / G：一般觀眾皆可觀賞。
  2. 保護級 / P：未滿六歲之兒童不得觀賞，六歲以上未滿十二歲之兒童需由父母、師 長或成年親友陪伴觀賞。
  3. 輔12級 / PG12：未滿十二歲不得觀賞。
  4. 輔15級 / PG15：未滿十五歲不得觀賞。
  5. 限制級 / R：未滿十八歲不得觀賞。

入場驗票時請出示年齡符合之證明文件。

本網站電影介紹頁面皆會標示每部影片的正確級數。

購票及取票時請依分級制度出示相關證明文件。
