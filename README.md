# MovieDay 電影院線上訂票系統

使用 Vue 3、Spring Boot 與 Oracle Database
開發的電影院線上訂票系統。

本專案從電影官網與線上訂票流程出發，使用者可以瀏覽電影資訊、查看最新消息、選擇電影場次、票種與座位，填寫購票人及付款資料並完成訂票。完成訂票後，訂單資料會儲存至
Oracle Database，不同電影場次也會根據既有訂單顯示對應的已售座位。

## 目前主要訂票功能與官網頁面已完成，下一階段預計加入會員系統。

## 專案功能

### 官網首頁

- MovieDay 官網首頁
- 活動輪播
- 熱映電影海報輪播
- 可從首頁前往電影介紹與場次資訊
- 使用 Swiper 製作輪播效果

### 電影介紹

- 顯示目前熱映電影
- 顯示電影海報、中文片名、英文片名、分級及上映日期
- 點擊電影後進入電影詳細資訊頁
- 顯示導演、演員、類型、片長及電影介紹
- 顯示電影預告片
- 可從電影詳細資訊頁前往訂票

### 最新消息

- 顯示影城最新活動與消息
- 顯示活動圖片、標題及日期
- 點擊消息後進入詳細資訊頁
- 顯示活動完整內容

### 電影場次

- 顯示電影名稱、海報、影城與日期
- 顯示不同語言版本及播放時間
- 自動判斷已經過期的電影場次
- 點擊場次後進入訂票流程
- 可預覽目前場次的座位狀態

### 票種選擇

- 選擇一般票與套票
- 調整不同票種數量
- 自動計算購票張數
- 自動計算訂單總金額
- 計算網路訂票手續費
- 未選擇票種時禁止進入下一步

### 座位選擇

- 顯示影廳座位圖
- 顯示一般座位、輪椅座位及已售座位
- 限制選取座位數量不得超過購票張數
- 顯示目前已選座位及剩餘待選數量
- 不同電影、日期與時間會顯示不同的已售座位
- 進入座位頁面時重新取得最新已售座位資料

### 購票人與發票資料

- 填寫姓名、手機及電子信箱
- 選擇雲端發票或公司發票
- 支援會員載具與手機條碼載具
- 驗證手機號碼、電子信箱及統一編號格式
- 必須同意購票須知才能繼續

### 付款功能

- 支援信用卡付款介面
- 信用卡號自動每四碼分組
- 卡號離開輸入框後自動遮罩
- 依卡號顯示信用卡類型
- 驗證有效期限與安全碼
- 訂票成功後顯示訂單編號與付款狀態

### 訂單與已售座位

- 使用 Fetch API 將訂單資料送至 Spring Boot
- 使用 Oracle Database 儲存訂單
- 從 /booking/list 取得歷史訂單
- 根據電影、日期及時間篩選目前場次
- 將訂單中的座位更新為已售狀態
- 完成付款後保存訂單資料

### 關於影城

- 戲院介紹
- 影城特色介紹
- 隱私權保護政策
- 線上訂票須知
- 電影分級制度說明

### 頁面導航

- 使用 Vue currentPage 控制不同頁面內容
- 使用 history.pushState() 更新網址
- 使用 popstate 處理瀏覽器上一頁與下一頁
- 重新整理頁面時可依網址參數恢復對應頁面

## 訂票流程

選擇電影場次
↓
選擇票種與數量
↓
選擇座位
↓
填寫購票人與發票資料
↓
選擇付款方式
↓
Vue 使用 Fetch 傳送訂單
↓
Spring Boot 接收訂單
↓
儲存至 Oracle Database
↓
回傳訂單編號
↓
顯示訂票完成頁面
